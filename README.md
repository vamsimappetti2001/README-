#### AI Self-Healing Test Agent *(in progress)*
An automation tool that closes the loop between test failures and test maintenance — a common bottleneck in real QA teams.
- Generates Playwright test scripts directly from plain-language task descriptions using the **Claude API**

- Built to reduce the manual triage time that usually eats into a QA engineer's week

`Claude API` `Playwright` `TypeScript` `Automation Tooling`
