### 🧭 About Me

I build end-to-end test automation frameworks and QA tooling, with a focus on **Playwright + TypeScript**. I care about writing tests that are reliable, maintainable, and CI-friendly — not just "green checkmarks."

Recently, I've been extending this into AI-assisted QA: building a system that generates and self-heals Playwright tests using the Claude API.

- 🔍 Currently deepening: Page Object Model, API testing, and CI/CD pipelines for test suites
- 🤖 Building: an AI agent that writes and auto-repairs Playwright tests from plain-language task descriptions
- 🌱 Background: hands-on automation practice across locators, hooks, iframes, visual testing, retries, and reporting (Allure + GitHub Actions)
- 🎯 Goal: QA / SDET role where I can own test strategy end-to-end
